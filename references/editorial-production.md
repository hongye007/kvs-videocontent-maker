# 口播、素材与剪辑执行规范

适用于项目介绍和以口播驱动画面的制作、修改与导出。目标是让观众理解内容，并减少版本遗漏、无效切换和重复生成。

## 项目叙述与事实边界

- 用“是什么 → 能完成的具体操作 → 使用价值”组织核心叙述。定义使用常见任务语言；专业术语用于解释必要机制，不替代用途说明。
- 每个项目围绕一条主要任务展开。用输入、操作和输出说明流程，其余功能由画面或补充文案承载。
- 表述区分已验证效果、官方功能说明和案例作者判断。“支持”不等同于本机运行成功；“给出复刻建议”不保证复刻质量、耗时或成本。
- 口语化以易听懂为准，避免未经证实的“轻松”“一键”“完美替代”等效果承诺。用户确认的措辞如需调整，说明事实依据，不擅自替换定稿。
- 精选指定仓库与实时热榜排名分开表述；星数、版本和日期使用同一次记录的口径。

## 素材选择与证据对应

先核对仓库 README、官网、文档和官方案例，再决定画面。官网关联产品与当前介绍项目分别核验，不因作者或域名相同而互用功能证据。

素材记录至少包含：来源 URL、获取日期、对应口播或功能、展示区域、素材类型、使用边界。视频另记录源时长、截取起止点与是否保留原声。

素材类型区分为官方演示、实际操作录屏、点击状态截图、文档功能说明和概念示意。截图不能标成连续操作，示意图不能当成运行结果；模型判断与人工验证分别标注。

先提供必要全貌，再用详情窗口或局部放大解释重点。文字密集的长页面按内容分块，不用一次缩小展示代替讲解。素材不足时使用可编辑流程、对比或解释卡片补充，不循环已有片段充数。

开源代码许可证不自动覆盖示例视频、人物、字体和音频。保留引用来源及独立授权的核实状态，不将公开可访问标记为已清权。

## 阅读节奏与运动分工

镜头按语义单元编排，不强制每句切画面，也不按统一秒数平均分配。时长同时考虑口播、画面信息量、观众是否首次接触及手机端可读性。

分镜记录区分“总时长”与“稳定可读时长”：后者不包含入场、遮挡和退场。短镜头出现多张卡片、密集截图或长标签时，优先减少文字、并排展示相关内容或合并相邻语义段；避免卡片刚入场就离开。

停留较长的镜头先判断是否仍在传递信息。需要持续观看的演示可保留；信息已表达完的画面可以收紧。必要的长镜头可通过局部强调、细节展开或布局变化推进，每次变化应对应新的解释，不为维持运动而重复推拉。

- 开场负责建立主题和观看预期，正文负责解释和举证。两部分可使用不同剪辑密度。
- 同一项目的项目名、说明和来源位置保持稳定；变化集中在素材区。素材可按内容缩放、移动、并排或切换布局。
- 转场承接相关内容，卡点优先对齐口播重音和语义转折；不以卡点为由截断必要的观看时间。
- 项目辅助色可用于卡底、编号和标注，正文保持可读对比；真实产品画面保留原色。配色与动效服从当前项目已确认的视觉方案，不固定套用本次示例。

## 修改范围与版本同步

修改前确认反馈针对的章节、元素和问题。对已确认保留的部分记录范围，例如开场动画、配色或章节信息；正文节奏调整不自动改写开场。

维护一份活动版本记录，指向当前稿件、配音、时间戳、字幕和时间轴，并记录文本哈希及音频文件身份。构建器从该记录读取，避免依赖多个手写文件名或写死的章节秒数。

每次文稿确认后检查此前接受的修改是否全部进入完整稿，再生成配音。修改影响按依赖向下传播：

```text
确认稿 → 配音及实际时长 → 字幕与词级时间戳
      → 语义锚点、章节边界、音效与素材截取 → 预览 → 导出
```

状态分别记录“稿件已改”“配音已生成”“预览已同步”“成片已导出”。若仅交付稿件，明确预览尚未同步；若任务包含视频更新，继续完成依赖项，不能以改稿代替完成。

语义锚点在所属章节内匹配；相同词语可能在开场与正文多次出现，不直接取全片首次出现位置。重建后检查章节顺序、素材截取范围及字幕覆盖；使用新媒体文件名或内容哈希避免缓存旧音频。

## 配音与高效验证

完整定稿优先生成一条连续配音。局部替换确有收益时保留原表现，按 `$kvs-continuous-tts` 的接缝检查执行；不能把供应商时间戳直接当作音频剪切点。

验证范围与修改影响对应：先核对稿件和实际音频，再检查受影响章节及相邻转场。低影响的配色或动画修改使用定点抽帧；新配音需重算受影响的后续时间轴。检查通过且无新增问题后进入下一阶段，不重复生成相同素材。

文字归一比对只能确认时间戳侧车与稿件一致，不能证明实际声音无漏词、重复或截断。对替换段及接缝试听；必要时转写实际合成音频，并检查编号、项目名、句首句尾。

最终文件需要从导出的 MP4 解码验收：检查视频和音频流、尺寸、帧率、时长、章节边界、尾帧及代表性画面，结合黑场和音量扫描。区分整帧取整差异与实际截断，不把预览通过当作成片验收。

## 导出交付

按用户要求提供成片、封面、字幕、口播、文案和来源记录，保存当前文件哈希并检查归档可读取。字幕已烧录时说明独立 SRT 的用途，避免上传后重复显示。

未指定平台时可交付通用母版，注明画幅、语言、可见链接及尚未执行的平台适配；不将通用导出宣称为多平台合规包。导出与公开发布分别授权，授权或权利状态未核实的项保留真实状态。
